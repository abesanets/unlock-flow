# Unlock Flow

Браузерное расширение (Manifest V3) для доступа к веб-интерфейсу Google Flow из неподдерживаемых регионов (включая Россию и Беларусь).

> [!IMPORTANT]
> **Важное уточнение о принципе работы:**  
> Google Flow накладывает **два уровня ограничений**:
> 1. **Сетевой (IP / Регион подключения):** Прямое обращение к серверам Google из РФ/РБ блокируется со стороны сети. Для открытия сайта по-прежнему требуется активный **VPN / Прокси / маршрутизирующий DNS** с выходом в поддерживаемую страну (например, США, ЕС).
> 2. **Региональный бан аккаунта / Feature-Gate:** Даже при активном VPN Google проверяет страну регистрации вашего Google-аккаунта через внутренний RPC `cPZSdc` и принудительно перенаправляет на страницу `/unsupported-country`.  
> 
> 👉 **Расширение Unlock Flow полностью решает вторую проблему:** оно перехватывает RPC-ответ на клиенте, активирует флаг доступа аккаунта и открывает полноценный рабочий интерфейс Flow.

> [!WARNING]
> **Срок жизни и стабильность:**  
> Решение основано на текущей реализации клиентской валидации в веб-приложении Flow. В случае, если инженеры Google перенесут жесткую проверку региона аккаунта исключительно на серверную сторону или изменят схему RPC `cPZSdc`, расширение может перестать работать в любой момент до выпуска обновлений.

## Основные возможности

- **Zero Dependencies:** Чистый JavaScript (ES2022+), никакого стороннего бандлинга и внешних библиотек.
- **MAIN World Injection:** Хук внедряется на этапе `document_start` через `chrome.scripting` до исполнения фронтенд-скриптов Flow (< 1 мс оверхеда).
- **Безопасность:** Работает локально в браузере, не собирает данные пользователя и активен строго на `https://flow.google.com/*`.
- **Автоматическая локализация:** Поддержка русского и английского интерфейса (Chrome i18n).
- **Встроенные тесты:** 47 unit & integration тестов на чистом Node.js.

## Установка

### Вариант 1: Без использования Git (Рекомендуется)

1. Перейдите в раздел [Releases](https://github.com/abesanets/unlock-flow/releases) и скачайте архив `unlock-flow.zip` из последнего релиза.
2. Распакуйте скачанный ZIP-архив в любую постоянную папку на компьютере (не удаляйте её после установки).
3. Откройте страницу управления расширениями в вашем браузере:
   - **Google Chrome / Chromium:** `chrome://extensions`
   - **Яндекс.Браузер:** `browser://tune` или `chrome://extensions`
   - **Microsoft Edge:** `edge://extensions`
   - **Brave:** `brave://extensions`
4. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).
5. В левом верхнем углу нажмите кнопку **«Загрузить распакованное»** (Load unpacked).
6. Выберите папку с распакованными файлами (в которой лежит `manifest.json`).

### Вариант 2: Через Git

```bash
git clone https://github.com/abesanets/unlock-flow.git
```
Затем загрузите папку через `chrome://extensions` аналогично шагам 3–6 выше.

## Инструкция по использованию

1. Включите ваш VPN/прокси с локацией в поддерживаемой стране (США / Европа).
2. Закрепите иконку **Unlock Flow** на панели расширений.
3. Перейдите на страницу [flow.google.com](https://flow.google.com).
4. Если вкладка уже была открыта и показывала `/unsupported-country`, откройте меню расширения и нажмите кнопку **«Обновить»** (она очистит адрес и перезагрузит сервис в разблокированном режиме).
5. Статус в расширении сменится на: `Разблокировано и активно`.

## Архитектура проекта

- `hook.js` — MAIN-world хук; перехватывает `XMLHttpRequest` и `window.fetch`, инспектирует batch-ответы RPC `cPZSdc`, подменяет булевы флаги доступности и пересчитывает UTF-8/UTF-16 байтовые префиксы фреймов.
- `background.js` — фоновый Service Worker; управляет динамической регистрацией скрипта перехвата при старте/обновлении.
- `status.js` — мост между страницей и расширением; передает диагностику и события состояния в popup.
- `popup.html` / `popup.js` / `popup.css` — лаконичный интерфейс управления.
- `_locales/` — файлы локализации (`ru`, `en`).
- `tests/` — тестовый раннер (`node tests/run.js`).
