# Unlock Flow

Браузерное расширение (Manifest V3) для доступа к веб-интерфейсу Google Flow из неподдерживаемых регионов (включая Россию и Беларусь).

## Описание

Google Flow выполняет проверку региональной доступности на этапе инициализации приложения. Расширение перехватывает ответ конфигурационного RPC-запроса `cPZSdc` протокола `batchexecute` на стороне браузера, активирует флаг доступности и пересчитывает framing чанков ответа. Это позволяет загрузить интерфейс и работать с сервисом без необходимости настройки сложного туннелирования для статики.

## Основные особенности

- **Zero Dependencies:** Чистый JavaScript (ES2022+), никакого внешнего кода или сборщиков.
- **MAIN World Injection:** Хук регистрируется через `chrome.scripting` и внедряется в контекст страницы на этапе `document_start` до выполнения скриптов Flow (< 1 мс накладных расходов).
- **Безопасность и приватность:** Расширение не собирает данные, не использует сторонние серверы и взаимодействует только с `https://flow.google.com/*`.
- **Автоматическая локализация:** Полная поддержка русского и английского интерфейса через Chrome i18n.
- **Встроенный тестовый набор:** 47 модульных и интеграционных тестов на чистом Node.js без внешних npm-пакетов.

## Установка

1. Склонируйте репозиторий или скачайте его как ZIP-архив и распакуйте в удобную папку:
   ```bash
   git clone https://github.com/<username>/<repo-name>.git
   ```
2. Откройте в браузере страницу управления расширениями:
   - В Google Chrome / Chromium: `chrome://extensions`
   - В Яндекс.Браузере: `browser://tune` или `chrome://extensions`
   - В Microsoft Edge: `edge://extensions`
   - В Brave: `brave://extensions`
3. В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).
4. Нажмите кнопку **«Загрузить распакованное»** (Load unpacked) в левом верхнем углу.
5. Выберите папку с проектом (где находится файл `manifest.json`).

## Использование

1. Закрепите иконку **Unlock Flow** на панели инструментов браузера.
2. Перейдите на [flow.google.com](https://flow.google.com).
3. При открытии popup-меню расширения вы увидите текущий статус:
   - `Разблокировано и активно` — хук успешно применил модификацию.
   - `Включено · Переоткройте вкладку Flow` — расширение готово к работе при следующей загрузке страницы.
4. Если страница открыта по адресу `/unsupported-country`, нажмите кнопку **«Обновить»** в меню расширения (она автоматически уберёт суффикс блокировки и перезагрузит страницу).

## Архитектура проекта

- `hook.js` — скрипт перехвата в MAIN world; обрабатывает `XMLHttpRequest` и `window.fetch`, инспектирует RPC-ответы `cPZSdc`, корректирует флаги и префиксы длины.
- `background.js` — сервис-воркер, управляющий регистрацией хука через `chrome.scripting` и сохранением настроек пользователя.
- `status.js` — изолированный контент-скрипт (ISOLATED world), передающий диагностические события из `hook.js` во всплывающее окно (popup).
- `popup.html` / `popup.js` / `popup.css` — интерфейс управления состоянием и быстрым переходом к Flow.
- `_locales/` — языковые пакеты (`ru`, `en`).
- `tests/` — автономная система тестирования (`node tests/run.js`).

## Тестирование

Для запуска тестов (требуется установленный Node.js 18+):

```bash
node tests/run.js
```
